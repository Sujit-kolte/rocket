# STES Rocketry — Website

A static website for STES Rocketry, a student-led rocketry team showcasing projects, team members, sponsors, and contact information.

## Description

STES Rocketry is a collegiate rocketry club focused on hands-on aerospace engineering and student development. This site presents the team’s projects and technical highlights, introduces subsystem leads and members, showcases sponsors and partners, and provides resources for outreach and collaboration.

## Features

- Project pages and assets
- Team members and subsystem leads
- Sponsor listings
- Contact and outreach pages
- Static, easy-to-host site (HTML/CSS/JS)

## Repository Structure

- `index.html` — Home page
- `members/` — Team members pages and assets
- `projects/` — Projects pages and scripts
- `sponsors/` — Sponsor pages
- `archive/`, `contact-us/`, `imgs/`, `backend/` — supporting folders

## Deploy (GitHub)

1. Push the folder to your GitHub repository (you already added remote):

```bash
git add README.md
git commit -m "Add README"
git push origin main
```

2. To publish as a website, enable GitHub Pages in repository settings (use `main` branch / root).
